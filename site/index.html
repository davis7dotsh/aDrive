adrive

A personal file drive that runs entirely on Cloudflare.

adrive is a small, self-hosted alternative to consumer file drives, built for exactly one user: you. File bytes stream straight into R2, metadata and append-only version history live in D1, and everything is served by a single Cloudflare Worker — no servers to run, nothing to patch.

What it does

  • Upload from a responsive dashboard or a streaming CLI.
  • Every replacement is a new version; history is append-only.
  • Tags, plus hybrid search: full-text, filename trigram, and optional semantic (Workers AI + Vectorize).
  • Public files get clean shareable URLs; private files use short-lived signed grants.
  • Publish whole static sites with adrive site put.
  • HTML and downloads are isolated on a separate cookie-less content origin, away from the dashboard.

How access works

One passcode signs you into the dashboard with a strict, host-only session cookie. The CLI authorizes itself through a device flow and gets a scoped API key — read-only or read/write, revocable at any time. Scheduled Worker maintenance sweeps expired sessions, trashed files, and storage lifecycle in the background.

Getting started

git clone https://github.com/davis7dotsh/aDrive
cd aDrive
pnpm install
pnpm db:migrate:local
pnpm --filter @adrive/web dev

The README walks through local setup, and docs/release.md in the repo covers deploying to your own Cloudflare account with two custom domains.
